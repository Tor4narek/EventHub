# EventHub MAX Web App

Мобильное React-приложение по макетам Figma: каталог, поиск, фильтры, карточка мероприятия, сохранённые, интересы и подборка. В браузере каталог и теги загружаются из публичных методов API. При запуске через MAX приложение использует `initData` для входа и персонализации.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173/`. Vite направляет `/api/*` на `http://localhost:8456`; backend должен быть запущен отдельно. Каталог и теги всегда загружаются из API. При недоступности backend показывается ошибка с кнопкой повторной загрузки.

## Docker

```bash
docker compose up --build -d
```

Команду выполняйте из корня общего репозитория после заполнения корневого `.env`. Откройте `http://localhost:5174/`. Compose собирает React-приложение и раздаёт его через Nginx. Запросы `/api/*` Nginx направляет на сервис `api` внутри общей сети Docker. Порт задаётся через `WEBAPP_PORT`. Проверка контейнера: `http://localhost:5174/health`. Остановить: `docker compose down` из корня.

Для размещения в MAX используйте production-профиль корневого Compose: Caddy выпускает TLS-сертификат для домена WebApp и перенаправляет запросы в контейнер. Браузер обращается к `/api` на том же origin, что и WebApp.

## Публикация

Соберите приложение командой `npm run build` или используйте корневой Compose. В общей Docker-конфигурации `VITE_API_BASE_URL` остаётся пустым: запросы идут через `/api` на том же origin, поэтому CORS не требуется. При отдельном размещении фронтенда задайте `VITE_API_BASE_URL` как HTTPS origin API до сборки и настройте CORS на backend.

В `index.html` подключён официальный MAX Bridge. Приложение использует `window.WebApp.initData`, `BackButton`, `getViewportSize` и `openLink`. При наличии `initData` выполняется `POST /api/auth/max`, затем `GET /api/me`. Токен хранится только в памяти приложения. Интересы из профиля автоматически включают фильтр каталога, если они есть. Кнопка «По интересам» временно снимает и возвращает фильтр, не удаляя интересы. Экран «Подборка» вызывает `GET /api/me/recommendations?limit=3` с Bearer токеном.

## API и ограничения

Используются публичные `GET /api/events`, `GET /api/events/{eventId}`, `GET /api/tags` и `GET /api/media/{objectKey}`. Метод `GET /api/tags/{tagId}` подготовлен в API-клиенте. Поиск, даты, формат, теги и пагинация передаются параметрами из OpenAPI. По умолчанию дата не выбрана. Лента показывает столько ближайших дней, сколько целиком помещается по ширине экрана; кнопка «Выбрать дату» открывает полный месяц с переходом между месяцами и полем для любой даты. Фильтр по выбранной дате можно сбросить отдельно.

В MAX профиль, сохранённые события и интересы общие с ботом. При входе и возвращении в приложение выполняются `GET /api/me` и `GET /api/me/saved-events`. Сохранение и удаление используют `POST` и `DELETE /api/me/saved-events/{eventId}`; изменение интересов — `PUT /api/me/interests`; включение еженедельной рассылки — `PATCH /api/me/settings`. Подборка загружается через `GET /api/me/recommendations?limit=3`. Все личные запросы передают JWT, полученный через `POST /api/auth/max`. Повторные нажатия блокируются на время запроса; при ошибке сохранение не отображается как успешное.

Вне MAX сохранённые и интересы остаются локальными и не включают напоминания. Старые локальные сохранения не переносятся в профиль автоматически. Если интересы не выбраны, параметр `Tags` не отправляется. В панели фильтров есть поиск по тегам для длинных списков. В обычном браузере персональная подборка недоступна без MAX авторизации.

**Контракт профиля:** `GET /api/me` возвращает `id`, `maxUserId`, `isWeeklyDigestEnabled`, `tagIds`. Если профиль или сохранённые нельзя прочитать, приложение показывает ошибку и кнопку повтора. Подписанные параметры запуска берутся из `window.WebApp.initData` или `WebAppData` в URL-фрагменте; подпись проверяет backend.

Проверка контрактов клиента: `npm test` (Node.js 22.6+). Сборка: `npm run build`.

Для запуска внутри MAX нужны публичные HTTPS URL API и WebApp. Значения `Format` отправляются как `offline`, `online` и `hybrid`.
