# EventHub Admin

Отдельная React + TypeScript админка для EventHubAPI с общей системой компонентов на Tailwind CSS. Браузер отправляет запросы на относительный путь `/api`; Nginx передаёт их сервису `api` в сети Docker.

## Запуск вместе с API

Админка и API запускаются из корня общего репозитория. Заполните корневой `.env` (образец — `.env.example`), затем выполните:

```powershell
docker compose up -d --build
```

Откройте `http://localhost:8457`. Данные администратора настраиваются только на стороне API; пароль, JWT-ключ и ключи MinIO не входят в сборку фронтенда. Для локальной разработки запустите `npm ci` и `npm run dev`; Vite проксирует `/api` на `http://localhost:8456`.

Импортёр пока отвечает 501, поэтому раздел импорта показывает только описание будущего процесса. Очередь проверки строится по `tagsConfirmed=false`.

Навигация и карточки используют общую систему стилей Tailwind CSS. Мероприятия и теги отображаются из EventHubAPI; поиск и фильтры мероприятий выполняются запросами к серверу. В контракте нет каталога интеграций, поэтому статичные карточки сервисов не показываются.
